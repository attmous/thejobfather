RUN LOCALLY

Start with Docker.

Docker installs the app’s Python and Node.js dependencies. Run the commands below, then add your Gemini key in Settings.

  1. 01

    Install Docker and Git.

    Install and open Docker Desktop ↗ (or Docker Engine + Compose on Linux). You’ll also need Git ↗ to clone the project.

    Already have Docker? Make sure its engine is running.
  2. 02

    Run the commands.

    Run these commands in Terminal or PowerShell. The first build downloads the app’s dependencies; later starts reuse them.

    When both services are healthy, open localhost:3000 ↗.

  3. 03

    Save your Gemini key.

    Create a key in Google AI Studio ↗. In the app, open Settings, paste the key, and select Save key.

    AI features need internet access and available API quota. Provider usage limits and charges apply.

SETUP AND DATA

Questions before you start.

Key requirements, data storage, and common setup problems.

Explore the source ↗
Does my data stay on my computer?+

Your workspace is saved locally in a Docker volume. Gemini receives the resume text or PDF, job content, and conversation context needed for AI features. During a call, microphone audio and any screen frames you choose to share are sent to Gemini. This is a local workspace with cloud AI, so it requires internet access.

Do I need my own API key?+

Yes. Add a Gemini API key in Settings before importing your resume or job. Your key is saved by the local backend with owner-only file permissions. There is no shared demo key. If Gemini reports a key or model error, check access and quota in Google AI Studio. Optional model overrides are documented in the repository’s .env.example.

Docker is running, but the app won’t open.+

From the project folder, run docker compose ps and docker compose logs --tail=60. Both services should be healthy. If port 3000 is in use, copy .env.example to .env, set JOBFATHER_PORT=3001, run docker compose up -d --wait, and open http://localhost:3001/.

If Docker can’t connect to its daemon, open Docker Desktop and wait for the engine to start. First builds need internet access to download dependencies.

What if a PDF, job link, or call doesn’t work?+

Use Paste text for an unreadable or locked resume PDF. Use Paste job description if a posting needs a login or blocks imports. For voice, allow microphone access on localhost and check that your API key can access the configured Gemini Live model. You can complete the workflow through chat.

What’s included in this hackathon build?+

Resume and job import, chat, live voice with optional screen sharing, fact approval, tailored drafts, cover-letter revisions, version history, and CV / cover-letter PDF downloads. It is a single-user local app. It does not submit applications for you. Owner sign-in and spoken document revisions are not included yet. GitHub and LinkedIn profile links are saved as references; they are not automatically imported as evidence.
